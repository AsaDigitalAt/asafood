# **App Name**: iFood Optimizer

## Core Features:

- Performance Diagnosis: Analyzes data provided by the user from iFood's partner portal, including sales funnel screenshots and top product photos.
- Data Extraction and Processing: Extracts key metrics from uploaded images using OCR and other image processing techniques.
- Personalized Action Plan Generation: Uses a generative AI tool to create a customized action plan based on the performance diagnosis, suggesting specific improvements for the restaurant to implement.
- Sales Funnel Visualization: Displays the sales funnel data in an easy-to-understand visual format.
- Discount Analysis: Analyzes discount data and provides insights on discount trends, including tendency and comprehensive analysis.
- Problem Identification: Highlights critical issues identified in the analysis, such as low conversion rates, with impact assessment.
- Interactive Checklist: Presents the action plan as an interactive checklist where users can mark tasks as completed.

## Style Guidelines:

- Primary color: Electric blue (#38bdf8) to represent energy, modernity and clarity. It will create a visual emphasis and guide the user through the app.
- Background color: Dark navy (#0F172A), providing a high contrast backdrop that is gentle on the eyes and gives the interface a clean and immersive feel.
- Accent color: Sky blue (#7dd3fc), for highlighting interactive elements. It maintains harmony and creates clear visual hierarchy, emphasizing interactive components and important information.
- Font: 'Plus Jakarta Sans' (sans-serif) for headlines and body text; this provides a balance of modernity, readability, and sophistication.
- Use consistent, minimalist icons throughout the interface to represent various features and actions. These icons should be clear and easily recognizable.
- Use a card-based layout to organize content into digestible sections. Ensure spacing and padding for a clean, uncluttered interface.
- Incorporate subtle animations for feedback, transitions, and loading states to improve the user experience.
